# 교차 검토용 전달 자료 (이슈 #12)

A가 정책 자료의 추출 결과를 교차 검토(#12)하고 정책·통합 수치를 대조(#20)할 수 있도록, B가 수집·추출한 결과에서 **제목과 본문을 뺀** 자료만 추려 둔 폴더다.

## 이 폴더에 있는 것

| 파일 | 행 | 내용 |
|---|---|---|
| `policy_documents_meta_2026-10-18.csv` | 147 | 문서 ID, 자료 유형, 출처, 발행일, 원문 주소, 분석 범위, 상태, 제외 사유, 중복 연결, 수집 시각 |
| `policy_document_keywords_2026-10-18.csv` | 54 | 문서 ID, 키워드 ID·이름, 맞은 표기, 출현 횟수, 사전 버전 |

**제목(`title`)과 본문, 내용 해시는 넣지 않았다.** 문서를 가리킬 때는 `document_id` 와 원문 주소를 쓴다. 두 파일은 `document_id` 로 이어진다.

## 왜 여기 두는가

`config/sources.csv` 의 재배포 조건이 `local_only_no_publish` 인 출처(국무원 정책 영문판, 중국과학원 영문판)는 **공개 산출물에 제목·본문을 실을 수 없다**(`CLAUDE.md` 규칙 4, `docs/source_policy.md` §3). 이 폴더의 자료는 그 조건 안에 있다.

- 제목·본문이 없다. 남은 것은 집계에 쓰는 값과 주소·발행일뿐이다
- 이 저장소는 **비공개**이고, 보는 사람은 같은 출처에 이미 접근 권한이 있는 협업자 둘뿐이다

## 저장소를 공개로 바꾸기 전에

**이 폴더를 지워야 한다.** 비공개를 전제로 둔 자료다. 지울 때는 작업 트리뿐 아니라 **이력에도 남는다**는 점을 함께 고려해야 한다(필요하면 새 저장소로 옮겨 공개한다).

같은 주의가 `docs/source_policy.md` §1 에도 적혀 있다.

## 어떻게 만들었는지

`data/processed/` 의 실행 결과에서 정책 문서만 골라 위 열만 추렸다. 수집·추출 명령은 `README.md` §3 과 같다.

| 항목 | 값 |
|---|---|
| 만든 날 | 2026-10-18 |
| 수집 범위 | 2026-09-05 ~ 2026-10-17 발행분 (출처별 최신 묶음) |
| 출처 | 과기정통부 보도자료, 백악관 OSTP, NSF, DOE, 국무원 정책 영문판, 중국과학원 영문판 |
| 사전 | `config/keywords.csv` v1 |
| 추출기 | `src/extract_keywords.py` (A) |
| 만든 사람 | B |

## 알아 둘 것

- 메타데이터 147행에는 **제외·실패 행도 들어 있다**(기간 밖, 발행일 없음 등). 분모와 제외 사유를 그대로 보라는 뜻이다. 분석 완료 행은 64건이다
- 키워드가 하나도 잡히지 않은 문서가 30건 있다. 대부분 비ICT 문서이며, 판단 근거는 `docs/policy_quality_review.md` 에 있다
- NSF·DOE 는 목록에서 과거 글을 받을 수 없어 최신 묶음만 들어 있다(`docs/source_policy.md` §4)
